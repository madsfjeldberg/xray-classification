# Setup
do
```
uv sync
```
to setup venv.

then, run the images.ipynb notebook to download, normalize and visualize the images. 

after this, you can run any of the other model notebooks; resnet, trees or mlp to train and test the models.

to visualize metrics, run the metrics notebook after training all models.

dataset: https://www.kaggle.com/datasets/muhammadrehan00/chest-xray-dataset
